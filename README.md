# LOUD LAND — 온라인 멀티플레이어 락페스티벌

여러 명이 같은 2D 페스티벌 필드에 접속해 이동, 피스, 점프, 달리기, 손흔들기, 인사, 돗자리 앉기 및 눕기를 함께 즐기는 웹 앱입니다. 메인 무대의 유튜브 영상을 모든 방문자에게 같은 곡/시간으로 동기화합니다.

## 실행

1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm start` (외부 패키지 설치 불필요)
3. 브라우저에서 `http://localhost:3000` 열기
4. 다른 사람이 접속하려면 이 프로젝트를 Node.js 서버를 지원하는 호스팅(Render, Railway, VPS 등)에 배포 후 HTTPS 주소를 공유하세요. 같은 Wi-Fi에서 테스트 시 서버 IP:3000으로 접속할 수도 있습니다.

## 조작

- WASD / 방향키: 이동. 휴대전화에서는 화면 왼쪽 하단 방향키.
- 1: 피스, 2: 점프, 3: 뛰기(움직일 때 빠르게 달림), 4: 손흔들기, 5: 고개 인사, 6: 앉기, 7: 눕기
- 앉기·눕기는 맵 아래쪽 돗자리 가까이에서 사용 가능.
- 입장 시 닉네임과 티셔츠 색을 선택.
- 오른쪽의 유튜브 URL 입력 후 PLAY를 누르면 모든 방문자의 재생 곡/시점이 변경됩니다. PAUSE/RESUME 역시 전체 공유.
- 각 방문자는 `ENABLE SOUND`를 눌러 본인 기기의 소리 재생을 활성화할 수 있습니다.

## 중요 제한사항

- 최신 브라우저의 자동재생 정책으로 음성은 방문자가 직접 한 번 허용해야 합니다.
- YouTube IFrame Player API를 정식으로 사용합니다. 원본 영상이 퍼가기 차단, 지역 제한, 비공개, 연령 제한이면 재생되지 않을 수 있습니다.
- 유튜브 영상 스트리밍을 서버에서 중계하는 것이 아니라 각 브라우저의 공식 임베드로 재생합니다. 네트워크 상태에 따라 약간의 시차가 발생할 수 있습니다.
- 본 버전은 임시 세션 방식입니다. 서버 재시작 시 접속자 및 재생 정보가 초기화되며 별도 계정/DB, 채팅, 권한/운영자 제어는 없습니다. 누구나 곡을 바꿀 수 있으므로 공개 운영 시 DJ 권한 및 도배 제한 추가를 권장합니다.
- 모바일에서는 기본 영상 정책에 따라 YouTube 재생 제한이 다를 수 있습니다.

## 구조

- `server.js` : Node.js HTTP + Server-Sent Events 멀티플레이어 서버. npm 의존성 없음.
- `public/index.html`, `style.css`, `app.js` : 페스티벌 무대, 공용 음악, 프로필 및 애니메이션.

환경변수 `PORT`를 호스팅 환경에 맞게 설정하세요.
