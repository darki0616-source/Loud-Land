ONEseason · MD / 인테리어 관리자

일반 유저 로그인과 별개인 관리자 도구야. MD 티셔츠와 텐트 인테리어 상품을 한곳에서 관리할 수 있어. 관리자 키는 이 페이지에서만 입력하고 GitHub에는 절대 넣지 마.

새 티셔츠 등록

투명 배경 PNG/WebP를 선택하면 최대 512×512 WebP로 변환해 등록해. 제작 권장: 1024×1024px 투명 PNG. 등록된 이미지는 캐릭터 몸통의 프린트로 사용돼.

등록 상품

테스트 모드: 모든 MD 무료 착용 / 기존 구매 포인트 환불. 이 페이지는 관리자 키 없이 등록·삭제할 수 없어.

🛋 텐트 인테리어 아이템

GLB 3D 모델을 업로드하고 상품명, 가격, 실제 3D 모델의 가로·깊이·높이를 정하면 게임의 아이템 상점에 반영돼. 새 상품은 GLB 파일이 반드시 필요해.

상품 목록

새 아이템 등록

이미 등록한 lantern.glb도 체크 후 저장만 하면 조명이 적용돼. 모델을 다시 업로드할 필요는 없어. 침대 머리판까지 포함한 전체 높이와 실제 눕는 매트리스 높이는 달라. 캐릭터가 떠 있으면 이 값을 낮추고, 파묻히면 높여줘. 기존 GLB는 재업로드하지 않아도 돼.

기본 상품을 수정할 때는 새 파일을 선택하지 않아도 돼.

모델을 드래그해 회전할 수 있어 · 아래 격자 한 칸은 게임 1단위 · 가로(X), 깊이(Z), 높이(Y) 입력 시 즉시 미리보기 반영

가로·깊이·높이 모두 실제 GLB 모델의 보이는 크기에 반영돼. 배치 점선도 같은 가로·깊이를 사용해. 원본 비율과 다르게 입력하면 모델이 늘어나거나 납작해질 수 있어. 판매 중인 상품의 가격을 바꿔도 기존 구매자에게 추가 청구하지 않아. 이미 배치된 상품의 가로·깊이를 수정하려면 배치 소품을 먼저 회수해야 해.
