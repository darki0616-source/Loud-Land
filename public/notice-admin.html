관리자 전용

✳ ONEseason 공지 관리자

실시간 전체 공지, 입장 안내, 상단 흐르는 공지를 각각 관리할 수 있어요.

🔐 관리자 인증

Render 환경변수 NOTICE_ADMIN_KEY를 사용하며, 설정하지 않은 경우 기존 MD_ADMIN_KEY를 사용할 수 있어요. 비밀번호는 이 페이지에 저장되지 않아요.

📣 즉시 전체 공지

전송하면 현재 접속 중인 모든 사용자에게 팝업이 바로 나타나요. 새로 입장한 사람에게 자동 반복되지는 않아요.

전송 기록 (기록 삭제는 이미 전송된 공지를 취소하지 않음)

🎟 입장 공지

신규 입장뿐 아니라 새로고침·자동입장 때마다 이 내용을 팝업으로 보여줘요. 여러 개를 등록하면 하나의 팝업에 차례로 표시돼요.

등록된 입장 공지

📢 상단 흐르는 공지

접속 중인 모든 사용자 화면 맨 위에서 오른쪽 → 왼쪽으로 흐르는 공지예요. 등록된 내용을 순서대로 하나씩 표시해요.

등록된 공지가 없으면 반복 표시하지 않아요.

등록된 흐르는 공지

공지 간격을 바꾸거나 흐르는 공지를 추가·삭제하면 다음 공지까지의 시간이 새로 시작돼요. 설정과 목록은 서버 저장소에 보관돼요.

관리자 키는 GitHub 소스에 넣지 마세요. 운영 서버의 Supabase 설정을 유지해야 Render 재시작 후에도 공지 목록이 남아요.
